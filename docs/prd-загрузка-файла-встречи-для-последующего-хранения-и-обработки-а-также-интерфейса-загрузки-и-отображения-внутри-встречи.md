# PRD: Загрузка файлов во встречах

**Дата**: 2026-09-28
**Статус**: Draft

## Цель

Дать создателю встречи возможность загружать файлы (документы, изображения, видео, презентации, PDF) для последующего хранения, чтобы все участники встречи видели превью этих файлов в чате и могли их скачать, не покидая интерфейс встречи.

## Пользовательские сценарии

- Создатель встречи выбирает файл в интерфейсе встречи -> файл загружается, хранится на сервере и появляется в чате встречи с превью.
- Участник встречи видит превью файла в чате -> скачивает файл одним действием.
- Участник встречи просматривает загруженные файлы после переподключения к встрече -> все ранее загруженные файлы на месте (хранение перманентное).
- Участник встречи пытается загрузить файл -> получает отказ: загрузка доступна только создателю встречи.
- Пользователь загружает файл -> до завершения загрузки видит прогресс, при ошибке получает сообщение.

## В скоупе

1. **Загрузка файлов** на бэкенд от создателя встречи:
   - типы: документы (doc/docx/odt/txt и т.п.), изображения, видео, презентации (ppt/pptx и т.п.), PDF;
   - максимальный размер одного файла — 2 ГБ;
   - ограничение по количеству файлов на встречу — не задаётся.
2. **Перманентное хранение** файлов на локальной файловой системе backend; файлы переживают перезапуск сервера и доступны в последующих сессиях встречи.
3. **Генерация превью** после загрузки:
   - изображения — миниатюра;
   - видео — один кадр;
   - PDF и презентации — первая страница;
   - документы — превью не генерируется, отображаются только имя и иконка типа.
4. **Интерфейс загрузки** внутри встречи: выбор файла, отображение прогресса и результата (успех/ошибка).
5. **Отображение файлов внутри встречи**: превью в чате встречи для всех участников.
6. **Скачивание файла** любым авторизованным участником встречи.
7. **Права доступа**: загружает — только создатель встречи; просматривают и скачивают — все участники встречи.

## Не в скоупе

- Индексация (полнотекстовый поиск по содержимому файлов).
- Конвертация форматов (например, DOCX/PPTX в PDF для просмотра в браузере).
- Просмотр документов/презентаций в браузере без скачивания.
- Редактирование файлов и совместная работа над ними.
- Удаление или замена файлов после загрузки.
- Облачное хранилище (S3 и аналоги) — используется только локальная файловая система.
- Общая квота хранилища на пользователя/встречу (кроме лимита 2 ГБ на один файл).
- Запись видео/аудио встречи как источника файлов.

## Технические ограничения

1. **Нет базы данных.** Метаданные встреч хранятся in-memory: при перезапуске backend список встреч и привязанные к ним файлы теряются, хотя сами файлы остаются на диске. Перманентность в этой итерации означает «файлы не удаляются и доступны, пока сервер не перезапущен», а не сквозную персистентность через рестарты. Полноценное перманентное хранение метаданных требует подключения БД — это отдельное решение.
2. **Локальное хранилище.** Файлы пишутся на диск сервера backend; при масштабировании на несколько инстансов или переносе сервера файлы нужно переносить вручную.
3. **Лимит 2 ГБ.** Ограничение накладывается на уровне приложения; нужно убедиться, что конфигурация Express/NestJS и промежуточное ПО (если появится) не режут запрос раньше этого лимита.
4. **Нет отдельной страницы встречи.** Сейчас встречи отображаются только списком на главной — интерфейс загрузки и отображения файлов «внутри встречи» потребует появления экрана/панели встречи, что само по себе меняет структуру frontend.
5. **Превью генерируются на сервере.** Для видео и PDF это нетривиальная обработка (извлечение кадра/страницы); в этой итерации допускается генерация в фоне после ответа на запрос загрузки — превью может появиться с задержкой.
6. **JWT-секрет захардкожен** в коде — существующая проблема безопасности, не связанная с этой фичей, но учитывается при работе с доступом к файлам.

## Критерии готовности

- [ ] Создатель встречи может выбрать и загрузить файл (документ, изображение, видео, презентация, PDF) через интерфейс встречи.
- [ ] Во время загрузки отображается прогресс; при успехе и при ошибке показывается понятный результат.
- [ ] Файл размером 2049 МБ отклоняется с сообщением о превышении лимита 2 ГБ; файл ровно в лимите загружается.
- [ ] После загрузки в чате встречи появляется запись с именем файла и превью (миниатюра для изображений, кадр для видео, первая страница для PDF/презентаций; для документов — имя и иконка).
- [ ] Превью отображается у всех участников встречи, а не только у загрузившего.
- [ ] Участник встречи может скачать файл по ссылке из чата; скачанный файл идентичен загруженному (проверка по хешу).
- [ ] Загрузка от участника, не являющегося создателем встречи, отклоняется (403).
- [ ] Скачивание файла неавторизованным пользователем отклоняется (401/403/404).
- [ ] Файлы, загруженные в предыдущую сессию работы сервера (без его перезапуска), доступны при повторном открытии встречи.
- [ ] Список файлов встречи доступен через API и содержит имя, размер, тип, дату загрузки и ссылку на превью.
