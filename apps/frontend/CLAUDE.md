# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Frontend-приложение платформы видеовстреч на Next.js 15 (App Router), React 19, TypeScript и Tailwind CSS. Часть NPM-монорепозитория — общие команды и структура описаны в `CLAUDE.md` в корне репозитория.

## Development Commands

Запускать можно как из этой директории, так и из корня через `--workspace=apps/frontend`.

```bash
npm run dev            # Запуск dev-сервера (порт 3000)
npm run build          # Продакшн-сборка
npm run start          # Запуск собранного приложения
npm run lint           # Линтинг (next lint)
```

### E2E-тесты (Playwright)

```bash
npm run test:e2e       # Все e2e-тесты (chromium/firefox/webkit)
npm run test:e2e:ui    # Интерактивный UI-режим
npm run test:e2e:debug # Debug-режим (пошаговая отладка)
npm run test:e2e:report# HTML-отчёт о последнем прогоне
```

Конфигурация: `playwright.config.ts`, тесты в `e2e/`. Playwright автоматически поднимает dev-сервер фронтенда; **backend (порт 3001) должен быть запущен вручную** перед запуском e2e.

## Architecture

- **App Router** — вся маршрутизация и страницы находятся в `src/app/`. Каждая страница — `page.tsx`, общий layout — `layout.tsx`.
- **Стилизация** — Tailwind CSS (`tailwind.config.js`, `postcss.config.js`), глобальные стили в `src/app/globals.css`.
- **TypeScript** — путь-алиас `@/*` указывает на `src/*` (см. `tsconfig.json`).
- **ESLint** — конфигурация наследуется от `next/core-web-vitals` (`.eslintrc.json`).

## Key Files

- `next.config.js` — конфигурация Next.js
- `tailwind.config.js` — пути для сканирования классов Tailwind (`src/app`, `src/pages`, `src/components`)
- `src/app/layout.tsx` — корневой layout, задаёт `<html>`/`<body>` и метаданные страницы
- `src/app/page.tsx` — главная страница

## UI/UX Quality Control

**КРИТИЧНО:** При любом изменении UI (новые компоненты, страницы, формы, стили, анимации) задача считается **незавершённой** до выполнения всех трёх шагов:

1. **Визуальное тестирование через Playwright MCP:**
   - Dev-сервер должен быть уже запущен (порт 3000 или 3001)
   - Используй Playwright MCP для автоматизированной проверки UI
   - Сделай скриншоты ключевых состояний (desktop/mobile viewport)
   - Протестируй основной сценарий использования
   - Проверь edge cases (пустые состояния, длинные тексты, ошибки валидации)
   - Проверь адаптивность (320px, 768px, 1440px breakpoints)
   - Проверь тёмную/светлую тему, если применимо
   - Убедись что изменения визуально корректны через скриншот

2. **UI/UX аудит через skill:**

   ```bash
   /ui-ux-pro-max
   ```
   - Загрузи skill и проанализируй изменения по приоритетным категориям
   - Проверь соответствие критичным требованиям (Accessibility, Touch & Interaction)
   - Проверь контраст цветов, размеры touch-целей, состояния фокуса
   - Исправь найденные проблемы перед завершением

3. **Документирование проблем:**
   - Если обнаружены проблемы — исправь их
   - Если исправление требует согласования с пользователем — опиши проблемы и предложи решения
   - Приложи скриншоты "до/после" при значительных изменениях

**Без выполнения этих шагов задачу нельзя считать завершённой.** Это касается всех UI-изменений: от мелких правок стилей до новых страниц.
